# Source licence check

Re-check every source before launch and every 6 months. Record what you saw.

| Source | Use | Licence page | What it says (paraphrase) | Checked on | By |
|---|---|---|---|---|---|
| PIB | content | https://pib.gov.in/Content/102_2_Copyright-Policy.aspx | Reproduction free of charge, no prior approval | | |
| RBI | content | https://www.rbi.org.in (Disclaimer) | | | |
| PRS Legislative Research | content | https://prsindia.org/aboutus/disclaimer | CC BY 4.0, credit PRS | | |
| PB-SHABD | content | https://shabd.prasarbharati.org/faqs | Free for registered media; logo-free; no credit needed | | |
| GDELT | discovery | https://www.gdeltproject.org | Free open data | | |
| Google News RSS | discovery | https://news.google.com | Headline + link only, internal | | |
| Newspaper RSS (each) | discovery | publisher's RSS terms page | Usually personal / non-commercial; headline + link only | | |

Rules the code enforces:
- Discovery sources: no text is stored; nothing from them is shown in the app or sent to the AI.
- Content sources: the AI writes original summaries; every article shows the source credit and link.
- Every AI draft waits for an editor before publishing.
